    Install it (one time)
    1. Unzip the download somewhere you'll remember.
    2. Open chrome://extensions in Chrome.
    3. Turn on Developer mode (top-right toggle).
    4. Click Load unpacked and pick the unzipped folder.
    5. It's installed! Find it in your extensions menu (puzzle-piece icon).

    Changed your mind later? You can pin it, disable it, or remove it from the same chrome://extensions page.

    Generated extensions run only on your machine. Review the code before loading anything you didn't write.
